## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer takes in many inputs and decides which 1 input to output/ send, and allows multiple sources to share one wire. 

### In plain English describe the function and use of a demultiplexer.
it does the exact opposite, it takes in 1 input and rotes it to 1 of several output locations. 

### What other uses might these circuits have? (Think Shannon’s)
Any logic gate can be implemented purely using a multiplexer by tying its lines to inputs, and combining multiple lower data streams into one high speed channel.
